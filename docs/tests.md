# Engine regression tests

An editor can land on the correct frame after the user lets go and still show a frozen movie while they drag. Keep a test for each behavior. The contracts below should survive changes to the project format, decoder, compositor and editor host.

## Embedding the engine

Run `just host-test` after changing the protocol or timeline. Compare a Node-requested picture at Signal Atlas frame 42 with the native CLI. With the OpenUSD SDK installed, `N4_TEST_OPENUSD=1 just host-test` also compares Field Unit at frame 70. Exercise nested keys and camera selection against native inspection data in Node. [Host tests and setup](../spikes/host/README.md)

Run `just editor-test` after changing selection, geometry or history. Compare masked picks with rendered pixels. Toggle root V2 in Signal Atlas and check the two affected ranges, the clean gap, undo, redo, save and a fresh reopen. A conflicting external save must preserve the draft and the on-disk edit. [Editor contract](../spikes/rfcs/0008-editor-session.md#first-headless-proof)

For imported SVG, pick opaque ink, a transparent hole over another layer, and a point outside the asset. Compare the picks with the composed pixels and require an outline for the selected occurrence. Break the linked file and reject the candidate. Warm picks and uncached renders should still use the accepted raster. Then fix the file and verify that picking and rendering change together. [SVG editor regression](../spikes/engine/tests/editor_svg.rs)

For editor geometry, pick through an animated ancestor mask at two placements of the same sequence. Compare the child hit and the click-through against rendered witness pixels, and check that marquee respects both transformed clip extents. Check wrapped text at its visible line, at an interior space, and beyond the occupied width. Edit the label, reload, and verify the attached layer follows its new anchor. Run ordinary native playback and export through the transport while keeping editor query work on demand. [Geometry regressions](../spikes/engine/tests/editor_geometry.rs)

For media picking, check an image through an animated crop and a transparent image against its accepted dimensions across a reload. Compare a transformed, masked video layer with rendered pixels at the start and end of its active interval. Click exposed implicit shot footage and check that selection addresses the timeline placement. [Media regressions](../spikes/engine/tests/editor_geometry.rs)

After changing how rectangles, paths or text are painted, run the engine tests on both painters: the default one, and the CPU reference with `N4_SKIA_GPU=0` or `--no-default-features --features openusd`. A native path and an SVG of the same shape must give the same bytes on the CPU reference. On the default pair they may differ by a rounding step along antialiased edges and at fractional corners.

For still WebP, compare a translucent decal with its lossless PNG control as it moves across a black and white background with a source blur. Check reversed seeks, composed thumbnails and the hash of the RGBA frames fed to the MP4 encoder. Replace the original with a file whose header still supplies dimensions but whose pixels are unreadable. Both filmstrip and isolated clip thumbnails opened after rejection must use the accepted artwork. Clear the optional alpha hint on a lossless WebP and compare its coverage with the original decal. Repair the file at a different size and check the new picture and pick area. [Decode fixtures](../spikes/engine/fixtures/webp) · [Image motion](../spikes/engine/tests/image_motion.rs) · [Editor reload](../spikes/engine/tests/editor_geometry.rs)

For animated WebP and GIF, scrub across a partial-frame disposal and compare the full picture against a moving plate with hand-authored PNG witnesses. For GIF, restore a temporary patch that covered both an opaque color and a hole, then clear a separate patch. Check a source thumbnail’s straight alpha and a composed thumbnail’s finished pixels separately. Include a portrait placement whose thumbnail width rounds up by half a pixel. Corrupt a later frame of an accepted asset, reject the replacement, then open both thumbnail workers and seek to an uncached frame. [Timed image tests](../spikes/engine/tests/animated_images.rs) · [Source contract](image-formats.md)

For live project reload, make real filesystem edits in a temporary project. Cover ordinary saves, replace-by-rename, a broken reference followed by a repair, and an unrelated file. Inspect the revision number and parked picture through a windowless session. An accepted transition must report its predecessor and damage scope. A rejected or unrelated change must leave the last accepted revision available. Compare the updated picture against a fresh open at the same frame. Keep this comparison as the oracle for selective invalidation and future editor commands. [Reload walkthrough](../spikes/host/README.md#live-project-reload) · [Damage fixtures](../spikes/docs/research/video-editor/live-edit-demo.md)

Run `just test-invalidation` after changing cache reuse or live edit reporting. Grading Signal Atlas’s shared survey changes `[0,64)` and `[128,192)`. Warm frame 64 must remain reusable and the overlaid track keeps its independent thumbnails. Mute the reprise and check that only audio changes. Roll the reprise camera cut one frame and compare its boundaries against a fresh native session. A formatting-only save leaves the occurrence cue and the 2D thumbnail damage empty. [Headless regression](../spikes/host/test/selective-invalidation.mjs) · [Thumbnail cache](../spikes/host/kit/test/thumbnail-cache.test.ts)

Verify engine ownership with a pipe-only client that issues no polling requests between a save and its change notice. [Native watch regression](../spikes/host/test/native-watch.mjs)

## Correctness suite

For a backward seek just before a key picture, its packet can already have an earlier decode timestamp. Seek to the requested picture’s own group of pictures and compare its visible frame ID with the original browser capture. Repeat at proxy resolution. [Native seek regression](../spikes/engine/tests/proxy.rs) · [Capture oracle](../spikes/engine/fixtures/screen-capture/check.py)

Qualify spatial import on a CPU-only path with the required OpenUSD SDK. Check the mesh and materials after stage composition and the exact prim or input reported for unsupported assets. In N4, move the source after opening the project and before the first draw. The accepted mesh must still render, survive a rejected revision and reuse its GPU upload. [Import profile](../spikes/spatial/openusd/PROFILE.md) · [Host regression](../spikes/engine/tests/usd_asset.rs)

Qualify the spatial pass with an independent host. Place a mesh through a textured plane with a transparent hole, render two cameras and repeat the first, then use the host’s own shader to composite the occlusion matte. Check known pixels on both sides of the intersection and require identical bytes when returning to the first camera. Run the production film through N4 separately to catch mistakes in timeline sampling and compositing. [Headless GPU host](../spikes/spatial/wgpu/examples/headless.rs)

For a rigid product with a live display, check the same part and material identities across a housing swap and hinge retime. Slip the screen video while holding its editable labels in place. Change the key light and check three regions independently: the cast shadow, the lit print and the unlit display. Reopen a changed hinge key at the parked frame through the editor and verify the selected property, revised pixels and thumbnail count. Keep rejected and superseded revisions in the regression suite.

For a two-dimensional backdrop shader, move a bounded mask across independent lettering and an image. Sample a known striped plate through the production shader to recover the rim's horizontal and vertical displacement. Verify the clear center, fractional edge, untouched exterior and sharply painted foreground. Exercise cropped and rotated placements, direct seek and sequential export.

For animated material inputs, round-trip a constant and a keyframed scalar through authoring, preserve slot order and sample them out of order on a trimmed layer. For glass fusion, measure the two original silhouettes and their smooth union at the same time. Require two connected components, then one while the original gap is positive, then two on release. Put a stripe chart under the production shader. The new neck must refract it and the buried interior rims must disappear when fully joined. Compare direct seeks to the encoder input.

For a held title with independently varying ink, disable each material strength and scramble its clock. Frames generated by the active effect must remain byte-identical after that change. With both strengths at zero, the title must stay still. Replace one word, check that the other word regions keep their pixels, and seek straight to the last frame of a hold.

For a moving monitor wall, check fixed cabinet landmarks across an authored pan. Mute one screen’s feed, then change its readout in a separate copy. Check the affected bounds at a visible frame and exact equality before the feed enters. Require out-of-order original-source seeks to agree with export. Exercise an active-profile set larger than the decoder capacity, plus a cut to zero active video. For sRGB-transfer footage encoded with a limited-range SMPTE 170M matrix, verify known neutral and chromatic patches at two decode sizes. [Media color tests](../spikes/engine/src/media.rs)

## Interaction and performance regressions

For read-only timeline inspection, follow a placement from the master into its layer hierarchy, select an animated property and click a key. Compare the displayed film frame, local sequence frame, local property frame and value against the authored timings. Use a child whose fade finishes while its parent is still moving. Also place one sequence twice with a camera cut on just the second occurrence. Switching uses at the same local frame must select the corresponding film frame and cut schedule. Check the CLI and graphical views against those same expectations, and hash the project sources before and after native interaction. [Navigation regressions](../spikes/engine/src/bin/player/inspector.rs)

For a cross-cut entrance, compare a shot-local reconstruction with one independently placed overlay. Check every frame and the audio extent. Reverse-seek through the cut and both ends of the overlay. On an opaque registration plate, widen the aperture about its center, then pan the plate under a held aperture. Measure both edges and compare interior pixels. On real footage, roll the base cut and move only the overlay in separate edits. A thumbnail at a covered media frame must show the composed picture.

For animated paths, compare an interpolated frame with a separately drawn static cubic. Edit a control point, seek backward, undo, and verify the unaffected endpoint poses. Include a cyclic weave over a patterned plate. Sample the visible over-strand and the real background exposed on both sides of each crossing.

For kinetic type, retime a foreground glyph and keep its exit and the underlying headline cues fixed. Compare exactly which pictures change, including frames adjacent to both entrances. Edit the headline, check its reflow, seek backward, then undo and reopen. Use a combining mark in a prefix test and a transformed shape with a known pivot to catch text segmentation and placement regressions independently.

| Trial to retain | What to check |
|---|---|
| Play, pause, step, drag, release and resume | Use the player's ordinary input handler. Supersede a seek while it is in flight, pause with playback frames queued, and release on a new target. The exact selected picture must remain parked. Resumed audio starts at the selected frame's sample boundary. |
| Recover from a picture stall before a cut | Delay the picture producer while audio continues. Verify the in-flight render can finish, every crossed shot presents its opening frame, and the final picture appears during play before parking. At the picture's audio lead limit, check for silence and verify the mix resumes at the first unconsumed sample. Cover fractional frame rates and repeat with a healthy producer. |
| Drag continuously in both directions | Drive pointer events from a clock independent of rendering. Record the requested frame, painted playhead and displayed movie frame. Include slow motion, fast sweeps, reversals and exact release. In the reporter’s synthetic test, a UI that repaints every event while displaying one picture must register zero picture changes. |
| Revisit and evict decoded pictures | Exercise 30 dispersed positions, revisit the same set, then traverse a range larger than the cache. Cross a keyframe backward and resume forward. Verify exact pixels after hits and eviction. Record cold and warm timings separately so a faster local scrub cannot hide a regression on distant revisits. |
| Play and scrub under background work | Run continuous playback with filmstrip, waveform and proxy generation active. Count missed presentation slots, consecutive misses and audio starvation. Repeat play/scrub cycles, drain the queues, and compare peak and settled memory across cycles. |

**Coverage to add.** The native scrub replay currently produces a report for review. Add a redistributable long-GOP fixture for the observed one-frame backward stall. Walk farther than the decoded cache holds, reverse from a keyframe to its predecessor, check both IDs, and record the longest picture hold. Also run a drag while import and thumbnail generation are active. The existing replay waits for the first picture, audio and all thumbnails. Use the [performance guide](performance.md) to qualify timing on a named device.

## Running the current suites

From the [engine crate](../spikes/engine/), run the following with FFmpeg and ffprobe available. The offscreen render tests need a Metal device. The all-features command below is for the Homebrew test Mac with SDL and FFmpeg development libraries installed.

```sh
cargo test --locked --all-targets
env LIBRARY_PATH=/opt/homebrew/lib cargo test --locked --all-targets --all-features
python3 -B tests/test_scrub_report.py
```

The Cargo suite covers library and integration tests. The Python command tests the scrub metrics. Choose additional checks according to the change.

- **Media timing or export.** Independently decode the numbered A/V cut and check the real variable-frame-rate capture against its capture log. Use a separately cleared long-GOP source when qualifying original-footage performance. [Native decoder checks](../spikes/engine/src/media/native.rs)
- **Compositing or editing.** Render the original and revised creator cuts, then exercise save, reload and asset replacement through the CLI. The Path replay changes one mask control point and checks the restored cut against every frame sent to the encoder. [Creator fixtures](../spikes/engine/fixtures/creator/README.md) · [Path replay](../spikes/engine/fixtures/creator/path-check.py) · [Session replay](../spikes/engine/fixtures/session_replay.py)
- **Transport or resource use.** Run the native control exercise, timed pointer replay and loaded playback on the target device. Keep the raw traces with the fixture and build identity. [Playback and memory workloads](../spikes/engine/fixtures/playback/README.md)
