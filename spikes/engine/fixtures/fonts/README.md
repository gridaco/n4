# N4 Grid Sans

An original stroke-drawn face for reproducible text layout, the native timeline and the example films. The drawing includes Latin letters, digits, punctuation, an ffi ligature, an accented e, a combining acute and three Hebrew letters used in the bidirectional selection test. The pen coordinates in the generator are the source for the outlines. Both the drawing and the generated font carry the [CC0 dedication](../../../../LICENSES/CC0-1.0.txt).

The compiled TTF is checked in. To change the drawing, install fontTools 4.60.2 in a Python environment and run `python3 spikes/engine/fixtures/fonts/build_font.py` from the repository root. Update any copies used in the example projects.
