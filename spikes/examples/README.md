# Example films

These two editable projects ship with the checkout. Each uses original assets dedicated to CC0. Paths, audio and project files resolve locally.

| Film | What to try |
| --- | --- |
| [Signal Atlas](signal-atlas/README.md) | [Copy the template and follow its agent guide](signal-atlas/AGENTS.md). Open the eight-second field survey. Edit the orange transect in one sequence and see it change in both placements. Toggle the V2 status indicator and compare the gap between them. |
| [Field Unit](field-unit/README.md) | Open an editable spatial product shot. Inspect its USD assembly, lighting, camera and instrument display. Requires the OpenUSD build. |

Run `just projects` to list the public projects or `just demo` to open Signal Atlas. Use `just viewer PATH` with a personal project under `.local/examples/` to open it in the same Electron harness.

## Choosing a production recipe

Start from a technique that worked in a reference study. A kinetic headline can hand emphasis from one word to the next through timed offsets and color changes. An editorial explainer can draw a route across a textured map, cut in to a detail and keep the ink registered through a camera move. Both are good briefs for a public example. Use cleared source material, write the copy for the new subject, and give the contributor a specific edit to try. Judge the result by how well the motion reads and how naturally that edit works.

Public submissions need the editable project, source or reproducible generator, and an asset-by-asset origin and license. See the [contributor guide](../../CONTRIBUTING.md).
