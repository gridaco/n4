# Working on the N4 engine

Read [CONTRIBUTING.md](CONTRIBUTING.md) and the [contract for the subsystem](docs/README.md) you are changing. Keep engine behavior and edit state testable through Rust and the headless CLI. Use the Electron harness to exercise host integration. Report the build and tests actually run, including any device or optional SDK required.

Public examples and test media need documented CC0 provenance. Keep private studies under `.local/`. When the assignment is to **make a film**, start with [llms.txt](llms.txt) and the instructions in the copied project. [Signal Atlas creator instructions](spikes/examples/signal-atlas/AGENTS.md)
